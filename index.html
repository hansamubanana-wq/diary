⚙️ Firebase の設定が必要です

このアプリは Firebase Realtime Database を使って日記を共有します。

設定手順：
1. Firebase Console でプロジェクトを作成
2. Realtime Database を有効化（テストモードで開始）
3. プロジェクト設定 → ウェブアプリ追加 → config をコピー
4. index.html の firebaseConfig と OWNER_PASSWORD を書き換えて再デプロイ

※ Realtime Database のルールを以下に設定してください（読み取り公開、書き込みはパスワード確認済みの場合）
{ "rules": { ".read": true, ".write": true } }
